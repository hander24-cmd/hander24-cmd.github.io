COMPLETED

MLB Expected Whiff Model

Independent Baseball Analytics Project

Developed a machine learning model using 711,897 MLB Statcast pitches to estimate the probability that an individual pitch generates a swing and miss.

Built and compared Logistic Regression and Gradient Boosting models using pitch velocity, movement, spin, location, pitch type, count, and handedness. The final Gradient Boosting model achieved a 0.751 ROC-AUC on a chronological test set.

Application: Used expected whiff probabilities to evaluate pitch types and identify pitcher-pitch combinations that generated more whiffs than expected.
